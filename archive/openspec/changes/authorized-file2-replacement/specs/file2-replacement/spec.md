## ADDED Requirements

### Requirement: Explicit bounded replacement
An explicitly authorized replacement SHALL require New Run mode and literal
boolean intent, verified fresh selected file2 existing Continue, bounded menu keys
and exact native New/file2 evidence. Default entries MUST retain their protections.

#### Scenario: User approves replacing current run
- **WHEN** explicit New Run replacement is invoked with verified file2 Continue
- **THEN** one bounded menu sequence selects New Run and accepts only native [New,2]

#### Scenario: Intent or state differs
- **WHEN** replacement is absent, used with Continue, lacks positive state evidence or starts another mode/slot
- **THEN** no replacement or further key sequence is accepted
