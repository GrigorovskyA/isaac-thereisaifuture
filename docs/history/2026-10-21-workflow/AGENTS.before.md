## RL and scientific integrity

Establish measurable baselines before PPO/RecurrentPPO. Reward coefficients are
hypotheses, not optimal constants or learned network weights. Version reward,
observation, and action schemas, configurations, seeds, and checkpoint lineage.

Separate train, validation, and test. Tune on validation; keep test held out until
final evaluation. Use comparable scenarios and budgets. Report several training
seeds and all episodes, including failures. Do not select a checkpoint from one
impressive run.

Do not reward empty ability use, repeated room entry, repeatedly damaging healed
HP, or dropping and picking up the same item. Measure gameplay success separately
from training reward. Test counterfactual builds outside the live episode.

## Checks and evidence

The baseline command is `./scripts/Check.ps1`: lint, format check, mypy, offline
pytest, pip consistency, and OpenSpec strict validation. Run the RL stack smoke
with `./scripts/Smoke-RL.ps1`. Its synthetic environment **does not verify Isaac**.
